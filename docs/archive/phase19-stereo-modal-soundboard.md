## 背景与声学机理

在 Phase 17 与 Phase 18 完成琴槌击弦物理与 88 键微观相位色散后，内置音源在单音物理振动上已具备极高保真度。然而，此前的单声道 8 峰音板输出导致声音完全固定在耳膜正中心（Mono-in-Stereo），缺乏大三角钢琴 2~3 米物理琴身下的立体声空间开阔感与琴盖非对称反射。

基于 Balázs Bank (2010 IEEE TASLP) 与 Juliette Chabassier (2019 IEEE SPM) 的现代数字钢琴模态理论，完成了对音板模态网络与空间辐射的深度重构。

---

## 核心实现明细

1. **16 峰物理云杉木音板模态组（Phase 19-A）**：
   - 将并联二阶谐振器从 8 峰扩充为 **16 峰**，频点覆盖 $48\text{ Hz} \sim 2250\text{ Hz}$；
   - 覆盖底箱呼吸模态、长琴桥低音耦合模态、肋木加强筋横向振动、正交各向异性板面模态与 1.85kHz 琴桥峰；
   - 双声道权重严格独立归一化（$\sum W_{\text{left}} = 1.00, \sum W_{\text{right}} = 1.00$），极点绝对稳定（$|r| < 1$）。

2. **琴桥立体声空间辐射与非对称投影（Phase 19-B）**：
   - 依据 88 键物理位置 $x_{\text{key}} \in [0.0, 1.0]$ 计算直达声声像定位：$\text{pan} = 0.20 + 0.60 \cdot x_{\text{key}}$（低音偏左 0.20 到高音偏右 0.80）；
   - 音板模态非对称空间投影：低频模态偏向左耳箱体，中高频模态偏向右侧开阔琴盖散射，彻底消灭单声道耳膜居中压迫感；
   - 单声道设备自动保持全额直通输出，立体声设备展现宏大自然的开阔声场。

3. **同音三弦独立三振荡器非对称拍频（Phase 19-C）**：
   - 中高音区（MIDI 48~108）三弦（Trichord）升级为真正的 3 振荡器非对称微失谐网络（$-\Delta c, 0, +\Delta c$）；
   - 3 根弦分别绑定 STFT 实测最优微初相矩阵 `kOptPhaseTable[0]`, `kOptPhaseTable[1]`, `kOptPhaseTable[2]`，展现真实调律师“合唱拍频（Choral Unison）”。

## 验证结果

- **三闸门基线**：`format --check` 0 违规，单元测试 57 类 11733+ 项断言 100% 满分通过，Windows MSVC 构建成功生成 `DevPiano.exe`。
- **立体声声像实测**：低音 A0 左声道能量比右声道高 1.5 倍以上，高音 C7 右声道能量比左声道高 1.5 倍以上，空间分离度极其清晰。
- **性能纪律**：零堆分配、零锁、纯加乘法递推，单核 CPU 维持 $\le 0.7\%$。
