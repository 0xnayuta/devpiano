## 1. 输入事实与实施边界

以下事实用于区分已有能力与新增任务，不替代现行特性契约：

- **频率与共鸣**：[TemperamentEngine](../../source/Audio/TemperamentEngine.h) 维护律制与 A4；[Piano88KeyTable](../../source/Audio/Piano88KeyTable.h) 仍为模型锚点插值。[PianoTuning](../../source/Audio/PianoTuning.h) 与 [PianoSynthVoice](../../source/Audio/PianoSynthVoice.h) 已区分第一分音、拉伸和刚度分音比，Duplex 非发音段与开放主弦交感分开。
- **音乐配置与保存**：[PerformancePreset](../../source/Layout/PerformancePreset.h) 保存绑定、区域、声学和固定层状态；[AcousticSnapshot](../../source/Audio/AcousticSnapshot.h) 保存完整执行参数。普通预设不保存插件实例、Master/ADSR 或音源选择，本机分区模式独立保存在 Settings。
- **踏板与物理输入**：[BuiltinSynthesiser](../../source/Audio/BuiltinSynthesiser.cpp) 保留逐通道 CC66 核心；应用接入未绑定 CapsLock，CC64/66/67 面向实际输出及原持有通道。完整小键盘 keyCode 经应用输入桥、绑定捕获和统一 ViewModel，不修改 JUCE。
- **固定层端点**：[AudioEngine](../../source/Audio/AudioEngine.cpp) 与两个 WAV 路径在 Instrument 内支持 Piano + 当前单 VST3；独立缓冲、层开关/增益和有界采样延迟不扩展为多插件槽位或通用路由图。
- **一次性身份**：Take 存储现场最终 MIDI 身份，下游不重套区域、Group、矩阵或快照移调；当前整数 v4 明确拒绝旧义而保护文件/会话。当前契约见 [录制身份回归](../issues/known-issues.md#已映射录制输入的重复移调当前最终身份契约)，不启动 Raw Key Note 重构。

实施遵守 [AGENTS.md §3.1](../../AGENTS.md#31-开发期减负与-yagni)、[项目边界](../reference/project-scope.md) 与 [架构契约](../reference/architecture.md)：保留增强模态模型路线、固定音频拓扑、NoteOff 原身份、采样级时序及产品自有实时契约；不以新功能为由推倒重写稳定模块。

## 2. Phase 37：物理建模调律与被动共鸣校准

目标：将调律、被动共鸣与钢琴风格建立在明确的频率语义、真实音频和可测实时成本上。不承诺与 Pianoteq 微观实现一致，也不宣称完成两项算法即可达到“声学巅峰”。

### Task 37-1：频率语义与声学基线

**实施内容**：

- 区分名义柔弦频率、实际第一分音、律制偏移、逐键拉伸、同音弦微失谐与毛毡老化扰动。A4 参考应对应关闭刻意微失谐时的实际第一分音基准，不要求有意失谐的每根同音弦都等于参考频率。
- 核对弦刚度、弦长、阻尼和模态参数的来源；已有插值锚点不冒充完整逐键实测。资料不能支持的琴型和拟真承诺不写成已标定事实。
- 使用生产渲染路径记录低、中、高音区及琴桥交界的分音、衰减、八度和复八度基线，说明采样率、力度、踏板、混响及微失谐条件。基线留在直接实施记录，不新建长期维护的研究平台。

**直接验收**：

- [x] 频率语义和量测方法明确，包括单弦/中心弦基准与同音弦拍频的区分；实际渲染数据可复核，不用 getter 或生产公式回算证明声音正确。
- [x] 记录当前基线及参数来源的可信边界；指标使用 Hz、cents、选定分音对的频差和衰减，不以主观形容词或测试数量验收。

**实施记录与改动前声音基线**：

- `Piano88KeyTable` 的出处线索为 `4e63ca2` 与 `1028e4d`：仓库内提供固定锚点、对数/线性插值及固定相位表，没有逐键测量记录或可复核的相位训练输入。保留这些模型常量，不将其认证为特定 Steinway 型号逐键实测或训练最优解；源码中相应未证实的标定说明已移除。
- 频率分层：`TemperamentEngine` 给出律制/A4 名义频率；Piano 的拉伸定义第一分音基准，再归一化刚度分音比；刻意老化扰动和同音弦相对失谐独立叠加。双弦采用基准两侧各半个相对偏移，三弦采用低/中心/高三频；第一分音基准不等于所有同音弦各自频率。
- Windows MSVC Debug 独立消费者运行真实 `BuiltinSynthesiser` / `PianoSynthVoice`，44.1/48 kHz、力度 0.35、核心参数均 0.5、老化 0、全开琴盖、Player 视角、未踩踏板、机械踏板音量 0；无房间混响。每音持续 4 秒再释放，保留 6 秒双声道 float WAV。

### Task 37-2：受约束的八度拉伸调律

**实施内容**：

- 在内置 Piano 频率链路实现关闭与经过校准的默认拉伸，保持律制独立；Sine 基准与 VST3 的 MIDI 输入不自动套用钢琴拉伸。
- 基线目标约定为：

  $$f_m=m f_T(n)2^{s_n/1200}\sqrt{\frac{1+B_n m^2}{1+B_n}}$$

  其中 $m$ 从 1 开始，$f_T(n)$ 是律制与 A4 换算结果，$s_n$ 是逐键拉伸音分，$s_{69}=0$。此式定义关闭刻意微失谐时的基线；同音弦和老化扰动的叠加另行明确，不混入名义频率定义。
- 选择并记录不同音区的分音匹配策略与可接受误差，受现有 $B$ 曲线、A4 锚点及音高顺序约束。Railsback 作为校准参考，不复制一条通用曲线，也不承诺消除全部音程拍频。
- 同轮更新受频率语义改变影响的实际消费者和回归；不得仅改 getter 期望值而没有真实音频证据。

**直接验收**：

- [x] 真实第一分音基准锚定 A4，保留 400.0–480.0 Hz 参考范围；拉伸关闭时符合新基线约定，历史律制保持独立有效。
- [x] 代表性音区及选定八度/复八度指标符合明确的校准目标；邻键音高顺序和范围边界有效。关闭拉伸且 $B=0$ 时退化为律制基准的谐波列，不引入除零或残余调律偏移。
- [x] 在常用采样率和受支持低采样率边界实际发声，保持 Nyquist 安全、有限输出和确定性；不通过改 MIDI 音符或全局 Pitch Bend 冒充逐键调律。

### Task 37-3：Duplex 非发音弦段被动共鸣

**实施内容**：

- 建模主弦发音长度之外的非发音弦段，明确频率、耦合、阻尼和衰减；由主弦能量激发，采用固定容量与有界处理成本。
- 与现有开放主弦交感分工明确；只调整受新增调律/共鸣影响的消费者，不将整套共鸣系统顺带推倒重写。
- 非发音弦段不以 CC64 或按键持有作为存在条件，但必须有有效激励才发声。核对 A4、律制与拉伸改变时的主弦/共鸣调谐关系，提供可旁路的声学控制。
- 本任务不建模 Blüthner 独立 Aliquot 第四弦，不用自由高频振荡、噪声或额外混响替代被动共鸣。

**直接验收**：

- [x] 未踩踏板时也能被主弦激发；无激励不自激，关闭后可旁路，频率与衰减变化可从真实音频辨识。
- [x] 长时间、多复音、采样率切换和参数边界下稳定，释放/Panic 后没有持续残留，尾音结束可观察。
- [x] 与现有交感和主混响组合不会重复计入能量；产品自有新增路径保持无锁、零堆分配与零库函数三角调用，增量成本实际测量。

### Task 37-4：可保存的钢琴风格预设

**实施内容**：

- 补齐风格实际需要的核心音色、拉伸和 Duplex 字段，沿用现有预设/快照及提交机制，不另建音色文件格式或完整琴型工厂。
- 提供少量经真实音频与受控试听区分的参数化风格，例如明亮、温润、近场或复古取向；不以现有宏观旋钮宣称完成 Upright、Honky-tonk 或 Fortepiano 物理结构复刻。
- 一键风格选择只提交其声学作用域，不意外替换键位、切换插件或覆盖全局调号；风格声学字段与 Master/其他独立参数的边界明确，普通演奏预设的既有映射职责不被取消。

**直接验收**：

- [x] 保存、重启、重新选择后实际音色和新声学控制有效恢复，不仅验证名称或字段回读。
- [x] 切换风格不污染输入映射或插件状态，不破坏已发音身份；音量匹配后的试听和音频分析能说明预设差异。
- [x] 当前格式缺省字段遵守明确默认值；保存/加载失败保持原文件与当前会话，不引入历史迁移、旧字段别名或双路径。

- **调律**：生产 Windows WAV 在 400/440/480 Hz 的 A4 中心搜索峰均位于目标，搜索步进 0.05 Hz、误差门槛 0.075 Hz；永久回归使用独立中心峰提取，门槛 0.07 Hz。默认拉伸下 A0 第四分音与 A1 第二分音实测差低于 0.05 Hz，关闭时差约 0.20 Hz；A3/A4/A5 保留同音三弦边峰，不把各自最强峰的 0.7/1.6 Hz 差冒充“中心分音失配”或承诺零拍频。8000/44100/48000 Hz 的实际发声、有限性与安全剪枝通过；Sine 新控制开关前后声音相同，且对照确有发声。

## 3. Phase 38：电脑键盘分区、三踏板控制与固定双层演奏

### Task 38-3：双模式物理键区、小键盘输入与统一映射看板

**固定布局与区域范围**：

- 设置中增加“键盘分区模式”，提供下表三个选项；首次无配置时为 `off`。仅支持两种固定分区模板，不增加上下分区、任意画区或通用区域路由引擎。

|---|---|---|
| 不分区（原有方式） / `off` | 不应用区域变换，沿用既有主键盘演奏路径 | 本轮新增的小键盘绑定不产生新起音 |

- 区域 A/B 是稳定的演奏角色，默认分别标注伴奏/旋律，但不限制音域或手的使用。两种布局共用一套区域参数，不复制两套矩阵或 Group；参数为通道、半音移调与八度偏移。区域通道默认 `0`（沿用逐键通道），可显式覆盖为 `1..16`；两个音高偏移默认均为 `0`。
- 区域在物理输入阶段按完整 keyCode 确定，不因移调后的音高越过阈值而换区。切换模式只改变区域归属，不重排或删除逐键绑定，不重置共享参数；同一主键盘按键可能改属另一区，下一次起音允许按新区域参数改变音高/通道。

- 不新增每区独立乐器槽位或 MIDI 文件按音高分流；两区仍驱动当前单音源或 Task 38-4 的同一固定双层。

**本机模式保存与演奏数据边界**：

- 模式通过 `SettingsModel` / `SettingsStore` 的本机设置保存，重启恢复最近的用户选择；不自动检测小键盘、不因没有收到小键盘事件而自动回退，不根据预设切换设备布局。
- 区域音乐参数与逐键绑定随 Performance Preset 保存并进入相应 Take 预设快照；本机模式不写入预设或 Take。加载/应用预设、原生演奏文件及回放快照只恢复其音乐配置，不改变本机模式。
- 模式切换不自动覆盖用户文件。未参与当前布局的小键盘定制仍保留；缺少绑定的位置明确显示未绑定，不临时补音。新建默认布局或用户显式恢复默认时才采用下面的初始映射，已有自定义布局不被自动补写。
- 录制沿用 Task 38-1 已明确的最终音符身份；原生回放、WAV、MIDI 导出与 MIDI 导入不根据当前物理模式重新划区或再套区域移调。本机布局不同不改变同一 Take 的音乐音高/通道。

- **恢复场景**：设置区域 A 的 Ch2、+2 半音/-1 八度后，A 起音为 MIDI50；区域 B 的 Ch3/+3 半音使 Num1 起音为 MIDI63。导入音乐预设保留本机模式；销毁并重新创建 MainComponent 后，`mainOnly` 与 Ch2/MIDI50 分别恢复。
- **固定双层**：逐采样比较两路与混合 PCM，验证层增益及一次公共 Master/Reverb；文件 A → 插件层禁用/重启 → 现场同音 B → 现场 B 释放的端点所有权反例已直接执行。逐通道 CC64/66/67 在新层起音前恢复；MIDI mutation 不污染另一层，零延迟不复活旧 ring，超容量实际静音后 prepare 恢复。
- **真实 VST3 SDK 基线**：build-owned `Phase38Probe.vst3` 报告并实际产生 128 采样延迟；实时/WAV、独立离线实例、真实 Editor、进度窗成功导出/Cancel、保持按键时重扫/加载及卸载均通过。fixture 不是商业厂商音色或稳定性认证。
- **工程门禁与保护**：`format --check`、Windows MSVC Debug app/tests、默认完整 CTest 和迭代边界 `tidy --all` 通过。Debug CRT 正控制检测到已知分配，测量中的双层音频回调堆分配为 0；不把它当成全部第三方堆/锁或 CPU SLA 认证。真实用户目录路径/字节/mtime/属性/SHA256 保持，私有 TEMP/TMP 清理完成。
- **证据与失败归属**：实际日志、receipt、PNG、MIDI、v4 Take 和 WAV 保存在 Windows `build-win-msvc/phase38-evidence`，一次性源码/driver 不进入产品。旧探针的前台消息回退、错误 NumLock 扩展位、已绑定窗口误找 Bind、短于 30Hz 刷新的视觉等待及重建后未聚焦均作为消费者问题修正；默认回归中的声明/转发/非空 oracle 退役，不放宽音乐身份或 PCM 容差。
- **保留边界**：没有 Release、≤0.7% 单核 CPU 认证、物理热插拔、rollover/去抖或商业厂商全矩阵验证；现有 2.0 秒 WAV 尾音截断与第三方永久阻塞的协作等待边界不改变。
