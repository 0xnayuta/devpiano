# ADR 009: 采用增强模态物理建模合成作为自主拥有、零采样依赖的默认内置钢琴音源

## 状态

已采用（Phase 12–14 完成，确立为唯一默认内置钢琴音色）。

## 背景

devpiano 在早期版本中使用内置正弦波合成器（`SineSynthVoice`）作为未加载 VST3 插件时的 fallback 音源。
虽然正弦波具备最小发声与验证能力，但存在以下严重不足：
1. **真实可听性差**：单调正弦音色无法提供弹奏钢琴的基本听觉反馈，严重影响脱离 VST3 插件时的使用体验。
2. **外部采样库依赖过重**：若采用基于 PCM/SFZ 采样的方案，将引入几十 MB 至数 GB 的音频采样资产，破坏项目轻量、零外部资源依赖的分发原则。
3. **CPU 算力与实时性要求**：物理建模必须在保证真实弦鸣音色（非谐波性、敲击冲击、同音弦微失谐拍频、音板共振）的同时，具备极低的 CPU 占用与零实时内存分配。

## 决策

1. **采用增强模态加法物理建模合成（Enhanced Modal Piano Synthesis）**：
   - 自主拥有、纯 C++ 算法实现，位于 `source/Audio/PianoSynthVoice.h`。
   - **刚性琴弦失谐（Stiffness Inharmonicity）**：遵循 JOS PASP 声学公式 $f_m = m f_0 \sqrt{1 + B m^2}$，准确再现钢琴特有的金属刚性泛音偏离。
   - **模态能量耗散衰减**：各分音按 Mutable Instruments 模态衰减公式独立指数衰减，高频分音随能量耗散迅速衰退。
   - **Magic Circle 递归振荡器**：采用二阶递归正弦振荡器（Coupled Form），逐采样仅需 2 次乘加即可生成纯正弦波，**零三角函数（`std::sin`）调用**，单核 CPU ≤ 0.7%。
   - **同音三弦微失谐拍频（Beating Effect）**：中高音区模拟钢琴同音三弦（Unison Strings）的微小频差干涉，赋予音色自然的律动感与生命力。
   - **8 峰音板共振器（Soundboard Resonator）**：构建覆盖 75~950 Hz 的多峰二阶带通滤波组，赋予琴弦声音真实的木质箱体共鸣。
2. **按音高动态分音剪枝（Partial Pruning）**：
   - 低音区 20 分音、中音区 14 分音、中高音区 8 分音、极高音区 6 分音，最大化音质与算力利用率。
3. **提供 SineSynth 与 PianoSynth 切换机制**：
   - 默认使用 Piano 物理建模音色，保留 Sine 正弦音色作为基准测试与对比选项。

## 原因

- **零资源体积**：核心代码仅一个头文件（~550 行），二进制增量 < 20 KB，完全无需外部采样文件。
- **高拟真度与表现力**：支持 Velocity 动态亮度和敲击硬度映射，音色丰富自然。
- **极高能效比**：Magic Circle 递归算法与分音剪枝消除了密集多复音弹奏时的 DSP 计算瓶颈。

## 影响

- 用户在未配置或未加载任何外部 VST3 插件时，即可获得高品质、低延迟的钢琴演奏体验。
- 离线 WAV 导出在无插件时默认渲染出物理建模钢琴声音，大幅提升导出音频品质。
