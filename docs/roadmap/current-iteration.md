### 外部研究输入与证据准入

`pianoteq9` 是独立研究仓库，其 `README.md`、`SUMMARY.md`、声学基准报告、Phase 1–5 规格书及保留 WAV 是候选研究输入，不是 devpiano 的运行或默认测试依赖。只吸收有来源的参数语义、可公开解释的方程和独立量测目标；不搬运反编译控制流、专有结构、商业二进制或音色资源。Clean-Room 声明不替代具体来源、独立推导与许可核对。

已识别的输入风险应在 Task 39-1 中复核，而非直接变成默认常数：

- 自动化脚本入口目前只打印初始化信息，未执行其宣称的完整 MIDI 生成、无头渲染与拟合链路；保留 WAV 的存在不等于流程可复现。
- 建议的指数 `B(k)` 曲线与报告锚点不一致，琴键序号和 MIDI 编号存在混用风险；C7 拟合频率与保留 WAV 谱峰的对应关系需要重新确认。
- 输出包络上升时间不能等同于琴槌接触时间或软件延迟；三力度高频占比变化不能唯一反推出毛毡接触指数。
- 正交静态投影不等于有效的同音能量耦合；振幅、功率、能量权重及其衰减时间常数必须区分。
- 研究 C++ 示例中的逐采样库函数三角调用及历史兼容建议不符合现行产品契约，不能原样移植。

不以报告的 Accepted、拟合优度、主观形容词或测试数量代替可复核证据。未经准入的结果继续标为假设；可信资料不足时保留明确标注的模型常量，不虚构全琴逐键实测或特定型号复刻。

## 2. Phase 39：可复核声学基线与三力度整音校准

目标：先取得可靠的频率、频谱和时间域输入，再在现有增强模态音源内实现连续力度整音，并完成状态、真实声音及实时成本闭环。不承诺复制 Pianoteq 微观实现或商业预设音色。

### Task 39-1：研究结论准入与统一量测口径

**实施内容**：

- 将引用结论区分为参数语义证据、黑盒观察、理论推导和工程假设，记录来源、目标版本、预设及实际生效的控制条件。外部软件输出不冒充真实钢琴直接测量。

**固定量测与实际消费者**：

- 钢琴键序号统一为 `pianoKey = midiNote - 20`；分音序号从 1 开始。柔弦 $f_\mathrm{soft}$ 与第一分音 $f_1=f_\mathrm{soft}\sqrt{1+B}$ 分开，第一分音再区分中心弦基准和同音混合峰，不把柔弦频率、A4 名义频率与最大峰互相替代。
- 生产覆盖 MIDI 21/24/36/43/44/48/60/69/72/84/96/108 × velocity 41/70/98 @48 kHz；另有相同音高的力度 70 @44.1 kHz、留出 MIDI 57/62 ×55/85，以及 A4 重复导出和 block 257 对照。没有扩展全琴扫描、通用平台或永久测量测试。
- 每音使用新导出拥有者、Ch1，0.2 秒起音、持音 8 秒、离键后观察 2 秒，再保留既有导出尾部 2 秒；实际 WAV 长 12.2 秒，全部输入 NoteOn/Off 与 MIDI 旁证按采样点核对，首个非零样本均位于 NoteOn。此观察不是声卡延迟或硬件反馈认证。
- 参数为 Brightness/Hardness/Resonance 各 0.5、A4 440 Hz、equal、默认拉伸开启、Duplex 0.15、老化 0、全开琴盖、Player、CC64/66/67 初始 0、踏板机械音量 0、Room wet 0、Master 1、双层关闭，调用者 ADSR 为 0.01/0.2/0.8/0.3 秒。保留音源内部琴槌、音板、琴盖/视角及公共限制器，不称为去除全部传递函数的裸弦输出；声部内部仍按现行规则处理 ADSR。
- 相对 NoteOn，频率窗为 0.08–3.8 秒；MIDI 96/108 使用 0.08–0.8 秒。单声道均值、去 DC、Hann、补零至至少 8 倍窗口并对 log-power 峰插值；真实尺度分别为 `1/T` 约 0.269/1.389 Hz，Hann 主瓣约 `4/T` 宽，补零不增加分辨能力。第一候选窗为名义频率 0.85–1.20 倍，第二候选窗为已选第一峰 1.70–2.30 倍；不根据期望 `B` 挪动频带或把不同赢家强称同一根弦。
- 频谱窗为 0.05–0.80 秒，功率为 `(|FFT(L)|² + |FFT(R)|²)/2`，在 20 Hz 以上归一化，HF 为 >2.5 kHz 功率占比并用 `10 log10` 表示。与 `(L+R)/2` 的相干抵消分开；低音极低 HF 可能受 24-bit 量化底限制，高音第一分音已超过门槛时 HF≈100% 不表示音色优劣。
- 原始 RMS 为 `sqrt(mean(stereo_samples²))`；前窗 0.1–0.3 秒，后窗 1.1–1.3 秒，另存 3.1–3.3 秒。后/前比包含拍频与包络混合，不当成单模态时间常数。起音采用前 0.15 秒内峰值的 10%–90% 因果 moving RMS，比较 10/20/40 ms 窗，以窗口终点记时；参考文件开头按零初始化仪表不证明其渲染前史。

### Task 39-2：受证据约束的逐键非谐性校准

**实施内容**：

- 只按 Task 39-1 已准入的可靠锚点调整刚度 `B`，保留音区和琴桥交界的物理解释；测量不足区域继续明确标为模型插值，不用一条未经验证的指数曲线覆盖全琴。
- 保持现行第一分音归一化与 A4 锚点：

  $$f_m=m f_1(n)\sqrt{\frac{1+B_n m^2}{1+B_n}},\qquad f_1(n)=f_T(n)2^{s_n/1200},\quad s_{69}=0$$

  其中 $m$ 从 1 开始，$f_T$ 为律制/A4 名义频率；同音弦和老化扰动在基准之外叠加。参考报告使用柔弦 $f_0$ 的拟合必须先换算语义，不能直接当第一分音输入。
- 同轮复核逐键拉伸、分音匹配、Duplex 段频率和开放弦共鸣的调谐，不只修改 `Piano88KeyTable`。校准仍独立于 MIDI 音符身份，Sine 与 VST3 不自动套用钢琴拉伸。
- 在修改前固定选定分音/音程的误差指标和可接受界限，使用未参与拟合的声音检验；没有足够证据的键位不以补齐“实测表”为验收目的。

**直接验收**：

- [ ] 可靠锚点与留出声音的分音误差符合事先约定的指标；插值及模型假设范围明确，没有伪造逐键或琴型标定。
- [ ] 实际 A4 400.0–480.0 Hz 锚点、选定八度/复八度、邻键音高顺序及原已起音身份有效；拉伸关闭且 `B=0` 的谐波极限不退化。

## 4. 验证纪律与文档维护

- **证据先于承诺**：先选定窗、指标、条件与误差界限，再实施和检验；改动后的结果不能反向决定通过门槛。参考输出只证明所测模型/条件，不认证商业微观机理、全琴常数或真实型号。
- **回归与风险成比例**：复用音乐身份、采样时序、数值稳定、生命周期和文件/会话保护防线；不新建通用声学平台，不用生产公式副本、字段存在、文案或测试数量验收声音。
- **平台门禁**：WSL 仅编辑和必要 configure；构建、软件测试及原生消费者在 Windows 镜像树 Debug 执行，命令及前置见 [quickstart](../guides/quickstart.md)。默认不发起 Release，优化构建的 CPU 认证需另行明确安排；全量 clang-tidy 只在迭代边界执行。
- **UI 与测试边界**：实际表面需观察；永久自动化 UI 测试遵守 [ADR-016](../decisions/ADR-016-headless-safe-pure-in-memory-ui-testing-pattern.md)，纯内存离屏、显式消息泵，不创建原生顶层窗口或跳过 headless。商业软件和原生窗口只用于独立消费者，不成为默认回归依赖。
- **尾音与外部依赖**：现有 WAV 固定 2.0 秒尾音截断不自动扩展；慢衰减基线使用足够长的持音而非截断尾部拟合。物理声卡、rollover/IME/DPI、商业 VST3 和跨机音色沿用 [现行验收边界](../reference/acceptance.md)，文档提交不构成补验。
- **最小同步**：新能力实现后才写入 [内置音源](../reference/features/builtin-piano-synthesis.md)、[预设](../reference/features/performance-presets.md)、[原生文件](../reference/features/performance-persistence.md)、[录制回放](../reference/features/recording-playback.md) 与 [离线渲染](../reference/features/plugin-offline-rendering.md) 的现行契约；本页只维护直接任务证据，项目状态和长期顺序以 roadmap 为准。已归档的 Phase 37/38 和历史审计不回写。
