## 2. 实施契约

1. 继续使用声明式 ValueTree 与内化 Flex 布局；测量只发生在 UI 线程并封装在 `ViewHost::fitToContent(width)`，不向业务暴露 raw GuiItem。
2. 先确定实际内容宽度并计算足够的预估高度，再按最终控件边界、margin、padding 与 border 收紧高度；不依赖固定窗口高度或平台标题栏补偿。
3. `JiveModalDialog::launchWindow()` 在原生标题栏模式确定后设置内容区尺寸、重新居中，再进入异步模态状态；保留既有所有权、回车、Escape、关闭及确认验证语义。
4. 标准操作行复用 `makeDialogButtons()`；28 逻辑像素底部留白、28 按钮高度、8 按钮间距、12 正文到操作区间距由 DesignTokens 维护。绑定/解除绑定位于左侧，确认/取消位于右侧；Notes 编辑区保留至少 80 逻辑像素。
5. 确认消息保留 40 逻辑像素最小高度，按字符换行支持不可分割长名称和显式换行；不缩小字体、不省略末行、不把空白搬到正文与按钮之间。
6. WAV 导出继续由独立 ProgressContentWrapper 和原工作线程管理；仅复用测量和窗口尺寸入口，取消仍发布协作请求，工作结束后才关闭并释放。
7. 删除旧固定高度参数和失效的树属性/赋值自证断言，不保留兼容别名；永久测试验证实际控件裁剪、重叠、末行完整性和 Notes 编辑行为。
