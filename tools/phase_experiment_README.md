# 45-2 phase-table experiment

Development-only workflow for the A/B/C1/C2 initial-phase experiment. It is
not part of the product build or package.

## Reference

The calibration reference is **Salamander Grand Piano V3** by Alexander Holm,
CC BY 3.0. No reference audio is committed to this repository.

- Official page: <https://sfzinstruments.github.io/pianos/salamander/>
- Archive: <https://archive.org/details/SalamanderGrandPianoV3>
- Official 48 kHz/24-bit FLAC remap: <https://github.com/sfzinstruments/SalamanderGrandPiano>

The Archive.org direct download endpoint did not negotiate TLS in this
environment. The official SFZ Instruments GitHub FLAC remap of the same V3
48 kHz/24-bit work was therefore used; it is not the `danielpodrazka/piano`
MP3 set.

Selected attack anchors:

- Notes: `C2, C3, C4, C5, C6, C7, C8` (MIDI 36/48/60/72/84/96/108).
- Velocity layers: `v4, v9, v13`, which cover MIDI velocity 37-43, 65-72 and
  97-104; the experiment labels them v41/v70/v98.
- Local reference directory used for this run:
  `/root/data/salamander-v3-48k24` (outside the repository).
- `tools/salamander_reference_manifest.json` records the upstream URLs and
  archive checksums. The local `SHA256SUMS.samples.txt` records the selected
  FLAC hashes.

## Candidate data

`tools/phase_candidates.json` contains:

- **A** — current production single row (`kOptPhaseTable`).
- **B** — upstream `danielpodrazka/piano` 3×64 table (MIT).
- **C1** — independently optimized single row.
- **C2** — independently optimized three rows.
- `decision` — actual-engine loss, peak and the selected production default.

A and B are MIT-licensed upstream data. C1/C2 were generated by
`phase_optimizer.py` against the Salamander reference and are experimental.

## Render candidate WAVs

The test binary can render candidates directly through `BuiltinSynthesiser`
without changing the production default:

```bash
/mnt/c/Program\ Files/PowerShell/7/pwsh.exe -NoProfile -Command \
  "& 'G:\source\projects\devpiano\build-win-msvc\devpiano_tests_artefacts\Debug\devpiano_tests.exe' \
   --acoustic-probe \
   --phase-experiment 'G:\source\projects\devpiano\build-win-msvc\phase_candidates.json' \
   --out 'G:\source\projects\devpiano\build-win-msvc\phase-experiment-4'"
```

This writes 0.5 s WAVs with NoteOff at 0.25 s and no Room reverb, plus
`phase_experiment_manifest.json`. The production `AcousticProbe` 120-case
path remains the source of full-key LUFS/True Peak evidence for the retained
default.

## Optimize / evaluate

The optimizer needs PyTorch CPU and NumPy. The workspace venv does not include
PyTorch; `/usr/bin/python3` from the Ubuntu packages does:

```bash
/usr/bin/python3 tools/phase_optimizer.py \
  --reference-dir /root/data/salamander-v3-48k24/wav \
  --candidates tools/phase_candidates.json \
  --output /root/data/salamander-v3-48k24/phase_candidates_optimized.json \
  --iterations 300
```

The script uses a phase-focused additive model built from the current
`Piano88KeyTable`/`PianoNoteSetup` frequencies, L1 weights, two-stage decays and
bloom. It is not a bit-exact production renderer; the actual C++ render is the
decision source.

Evaluate actual engine WAVs against the reference:

```bash
/usr/bin/python3 tools/phase_eval.py \
  --reference-dir /root/data/salamander-v3-48k24/wav \
  --experiment-dir /mnt/g/source/projects/devpiano/build-win-msvc/phase-experiment-4 \
  --output /root/data/salamander-v3-48k24/phase_eval_4.json
```

## Result

Actual-engine attack metrics (21 anchors, lower spec is better):

| Candidate | mean mel-STFT | mean peak | peak factor ratio | flux ratio |
|---|---:|---:|---:|---:|
| A | 2.174 | 0.0963 | 0.924 | 0.561 |
| B | 2.050 | 0.0295 | 1.041 | 0.639 |
| C1 | 2.177 | 0.0935 | 0.894 | 0.562 |
| C2 | 1.966 | 0.0557 | 0.841 | 0.638 |

**Decision: retain A.** C1 did not beat A. B and C2 lose about 69% and 42% of
average peak level; B is not better than A, so C2 is not eligible under the
phase-plan gate. The production phase table and voice output path are
unchanged.

## Limitations

- The optimizer model is phase-focused and omits Room/body IR and exact
  production nonlinearities; the actual C++ render is the decision source.
- C1/C2/B were rejected on 21 attack anchors before full-key LUFS/TP
  measurement; only the retained A went through the 120-case full-key probe.
- No human listening test was performed for the experimental tables.
